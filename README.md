🎰 Python 아케이드 게임 통합 플랫폼 (통합 카드 게임 & 슬롯머신)

Python 기말과제를 위해 제작된 Tkinter 기반의 멀티 게임 플랫폼입니다. SQLite 데이터베이스 기반의 회원가입 및 로그인 시스템을 통해 유저 세션 관리와 전적(승/패, 승률, 보유 칩)을 안전하게 기록하며, 정통 룰이 반영된 세븐 포커, 텍사스 홀덤, 슬롯 머신, 그리고 승률 기반 랭킹 보드를 제공합니다.

🛠️ 주요 기능 및 시스템 소개

1. 회원가입 및 로그인 (database.py 연동)

SQLite 데이터베이스를 활용하여 사용자별 아이디, 비밀번호, 닉네임, 전적(승, 패), 보유 칩(Chips)을 관리합니다.

파산(칩 부족) 시 자동으로 기본 칩이 충전되어 지속적인 플레이가 가능합니다.

2. 🃏 세븐 포커 (Seven Poker)

정통 룰 반영: 총 7장의 카드를 순차적으로 받으며, 내 3번째 카드와 AI의 3번째 카드가 서로에게 오픈되어 견제와 전략적인 베팅이 가능합니다.

마지막 7번째 카드는 히든(뒷면) 상태로 유지되다가 쇼다운 시에 전체 공개됩니다.

7장 중 가장 유리한 5장을 조합하여 족보를 판정하며, 카드 배분 및 공개 시 순차 플립 애니메이션이 적용됩니다.

3. 🎲 텍사스 홀덤 (Texas Hold'em)

프리플랍(개인 2장) ➔ 플랍(공용 3장) ➔ 턴(공용 4장) ➔ 리버(공용 5장) 단계별 베팅 시스템을 지원합니다.

내 홀 카드와 공용 카드를 조합하여 AI와 최고 족보 승부를 펼치며, 플랍·턴·리버 및 쇼다운 공개 시 카드 넘김 애니메이션이 동작합니다.

4. 🎰 슬롯 머신 (Slot Machine)

3개의 릴(Reel)이 순차적으로 회전하며 멈추는 애니메이션(root.after 기반)을 적용해 실제 회전감을 높였습니다.

심볼(🍒, 🍋, 🍊, 🍇, 🔔, 💎, 7)을 맞추는 미니게임으로, 7 잭팟 및 트리플/더블 당첨 배율에 따라 대량의 칩 보상을 획득할 수 있습니다.

회전 중에는 중복 클릭과 화면 이탈을 방지하기 위해 버튼 상태를 잠금 처리합니다.

5. 🏆 승률 기반 명예의 전당 (랭킹 보드)

전체 유저들의 전적 데이터를 바탕으로 승률이 높은 순(승률 = 승리 / (승리 + 패배) * 100)으로 정렬하여 1등부터 10등까지의 순위를 보여줍니다. (승률 동률 시 승수가 많은 순으로 정렬)

상위권 유저에게는 특별한 메달/왕관 표시(👑)를 부여하여 경쟁 요소를 강화했습니다.

🐛 개발 과정 및 트러블슈팅 내역

튜플 비교 및 타입 에러 (TypeError) 해결

이슈: 7장 중 최적의 5장을 조합하는 알고리즘에서 동점자 처리 시 키커 값 비교 과정에서 튜플 타입 불일치 에러 발생.

해결: 초기 베스트 콤보 값을 명시적인 빈 튜플 ()로 설정하고, 족보 점수와 값 튜플 비교 로직을 정교화하여 예외 상황을 원천 차단함.

세븐 포커 오픈 패 가시성 개선

이슈: 플레이어와 AI의 오픈 카드 규칙이 시각적으로 명확히 구분되지 않음.

해결: 정석 룰에 맞추어 "내 3번째 카드"와 "AI의 3번째 카드"를 서로 오픈 상태로 표기하고, 라벨 배경색과 텍스트 태그를 다르게 지정하여 가시성 극대화.

슬롯 머신 숫자 '7' 심볼 깨짐 현상 해결

이슈: 시스템 환경에 따라 7️⃣ 이모지가 네모 박스로 깨지거나 정상 출력되지 않음.

해결: 이모지 대신 일반 텍스트 문자 7을 사용하고, 굵은 폰트(Arial, 40, bold)와 빨간색 강조 컬러(fg="red")를 적용하여 깔끔하게 출력되도록 수정.

포기(Fold) 시 UI 보존 및 다시하기 추가

이슈: 게임 도중 다이(Fold)를 선언하면 즉시 로비로 튕기거나 연속 플레이가 불가능함.

해결: 폴드 시에도 칩 차감 및 패배 기록이 정상 반영되며, 승패 결과 화면과 동일하게 [🔄 다시하기] 및 [🏠 게임 선택 로비] 버튼이 노출되도록 개선.

페어 상세 정보(카드 숫자) 명시

이슈: 단순히 "원페어", "투페어"로만 결과가 표시되어 어떤 숫자의 페어인지 파악하기 어려움.

해결: 역값 매핑(rev_val_map)을 도입하여 "A 원페어", "K·10 투페어"와 같이 구체적인 카드 숫자가 함께 출력되도록 업그레이드.

승률 기준 정렬 랭킹 보드 도입

이슈: 단순히 칩 보유량으로만 순위를 매기면 게임을 많이 한 유저의 실력적 우위나 성취도를 반영하기 어려움.

해결: 승률 계산 알고리즘을 도입하고, 승률 ➔ 승수 ➔ 보유 칩 순으로 정렬 기준을 세분화하여 공정하고 흥미진진한 랭킹 시스템 구축.

슬롯 머신 회전 및 카드 뒤집기 애니메이션 추가

이슈: 슬롯 결과와 카드 공개가 한 번에 즉시 바뀌어 연출감이 부족하고, 연속 클릭 시 상태가 꼬일 여지가 있음.

해결: root.after()를 활용해 슬롯 릴 순차 정지 애니메이션과 카드 플립(| ➔ 🂠 ➔ 카드) 애니메이션을 구현하고, 애니메이션 재생 중 잠금 플래그(is_spinning, is_card_animating)로 버튼 연타를 제어함.
